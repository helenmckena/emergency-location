# Автоматическая отправка ссылки в WhatsApp (бесплатно, до 5 номеров)

Оператор вводит номер, и ссылка сама приходит человеку в WhatsApp. Работает через тестовый режим WhatsApp Cloud API от Meta: тестовый номер бесплатный, но писать он может только на **5 заранее подтверждённых номеров**. Для защиты и демо этого хватает. На любой другой номер сообщение не уйдёт (заявка всё равно создастся, а ссылку можно отправить кнопками Telegram, WhatsApp, SMS).

## 1. Создать приложение в Meta (10 минут)
1. Откройте developers.facebook.com, войдите через Facebook и нажмите Create App, тип Business.
2. Добавьте продукт WhatsApp. Meta сама создаст тестовый аккаунт и тестовый номер.
3. WhatsApp, API Setup: скопируйте **Phone number ID** (это не номер телефона, а длинный идентификатор).
4. В блоке To, Manage phone number list добавьте до 5 номеров (свой, Зейнеш, Марал и т.д.). На каждый номер код придёт **в WhatsApp, а не по SMS** (сообщение от WhatsApp или Meta). Вводите номер в международном формате (+7 708 ...), на номере должен быть установлен WhatsApp. Если код не пришёл, подождите пару минут и запросите повторно.
5. Нажмите Send message (шаблон hello_world) на каждый номер и убедитесь, что сообщение дошло.

## 2. Постоянный токен
Временный токен из API Setup живёт около 24 часов. Постоянный делается бесплатно:
Business Settings, Users, System users, Add (роль Admin), затем Generate token с правами `whatsapp_business_messaging` и `whatsapp_business_management`. Токен никому не показывайте и не выкладывайте в GitHub.

## 3. Создать шаблон сообщения
WhatsApp Manager, Message templates, Create template:
- категория **Utility**, название **share_geolocation_request**, язык **English**;
- текст: `Emergency services request. Please open this link and share your location so we can help you: {{location_link}}`;
- тип переменной **Name**, имя переменной **location_link**, в примере вставьте любую ссылку.

Дождитесь статуса Approved (обычно от нескольких минут до часов). Если шаблон отклонили, перепишите текст подробнее и подайте заново.

## 4. Переменные на Render
Добавьте к уже заданным:

    DELIVERY__WHATSAPP=true
    WHATSAPP__GRAPH_API__PHONE_NUMBER_ID=ваш_phone_number_id
    WHATSAPP__GRAPH_API__ACCESS_TOKEN=ваш_постоянный_токен
    SERVER__FRONTEND_URL=https://адрес-вашего-сайта-на-vercel

Если шаблон создан на другом языке или под другим названием, добавьте `WHATSAPP__TEMPLATE_LANGUAGE` (например `ru`) и `WHATSAPP__TEMPLATE_NAME`.
`DELIVERY__SMS` оставьте выключенным: SMS платные.

## Какие 5 номеров брать
Любые номера с WhatsApp, к которым у вас есть доступ в момент подтверждения: ваш, Зейнеш, Марал и запасной. На демо оператор вводит один из этих номеров, и на этот телефон приходит сообщение в WhatsApp со ссылкой.

## 5. Проверка
Оператор вводит один из 5 подтверждённых номеров: через несколько секунд в WhatsApp приходит ссылка. Сообщение будет от тестового номера, это нормально.
Если не пришло, смотрите логи Render: ошибка `131030` значит, что номер не в списке из 5.

## Если проверяющий вводит свой номер, которого нет в списке
Сообщение на такой номер не уйдёт (так устроен тестовый режим Meta), но заявка создаётся. На странице заявки:
1. Кнопки WhatsApp и Telegram открывают чат с введённым номером из аккаунта оператора, ссылка подставляется сама. Работает для любого номера, но отправить нужно вручную.
2. Кнопка «Копировать ссылку» копирует ссылку для пострадавшего: её можно вставить в любой чат или открыть на втором телефоне.
3. Заранее (если удастся) добавьте нужный номер в список 5: на него придёт код в WhatsApp.
