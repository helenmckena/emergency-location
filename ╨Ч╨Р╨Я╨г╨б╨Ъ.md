# Запуск Emergency Location (бесплатно, без SMS)

Что изменено: ссылку пострадавшему отправляет оператор в один клик (Telegram, WhatsApp, SMS с его телефона). Платные Twilio и WhatsApp API выключены, Postgres и Redis не нужны.

## 1. Проверить на своём компьютере
Бэкенд (нужен Python 3.12+):

    cd backend
    pip install -r requirements-local.txt
    cp env/.env.local.example env/.env
    cd app
    python main.py            # http://localhost:8000

Фронтенд (в другом терминале):

    cd frontend
    cp .env.example .env.local
    npm install
    npm run dev               # http://localhost:5173

## 2. Показать на двух телефонах (нужен интернет-адрес)
Геолокация в браузере работает только по HTTPS, поэтому нужны Render (бэкенд) и Vercel (фронтенд), оба бесплатно.

Render, New Web Service из GitHub:
- Root Directory: `backend`
- Build: `pip install -r requirements-local.txt`
- Start: `cd app && uvicorn main:main_app --host 0.0.0.0 --port $PORT`
- Переменные: `DB__DSN=sqlite+aiosqlite:///./local.db`, `SERVER__DOMAIN=https://ваш-сервис.onrender.com`, `LOCATION__NEXT_REQUEST_WAIT=0`

Vercel, Settings, Environment Variables, затем Redeploy:
- `VITE_DEMO_MODE=false`
- `VITE_API_URL=https://ваш-сервис.onrender.com`

Бесплатный Render засыпает через 15 минут: откройте адрес бэкенда за минуту до выступления. База хранится во временной памяти и очищается при перезапуске.

## 3. Как показывать
1. Оператор открывает /operator, вводит номер, нажимает «Запросить геолокацию».
2. Нажимает «Telegram»: откроется чат с этим номером, сообщение со ссылкой уже скопировано, его нужно вставить и отправить.
3. На втором телефоне нажимают ссылку и делятся геопозицией: точка появляется у оператора.
